# Cloud Native Architectures — public lab assets

Files that the labs of the Cloud Native Architectures course at ELTE download
into Azure: sample applications, Docker Compose stacks and configuration. The
lab instructions are in the course repository. Nothing here is secret.

| Directory | Lab | Contents |
| --- | --- | --- |
| [`lab-07`](lab-07) | Observability | The Notes app instrumented with OpenTelemetry, an OpenTelemetry Collector, Jaeger and Prometheus behind nginx, and the cloud-init script that starts them on a VM |
